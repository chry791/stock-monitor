    Collega GitHub per aggiornare il mercato

    Questo collegamento permette al pulsante di avviare Radar nuovo nel tuo repository stock-monitor.

    1. Apri la creazione del token GitHub.
    2. In Repository access scegli Only select repositories, poi stock-monitor.
    3. Controlla che Actions abbia Read and write; non aggiungere altri permessi. Metadata: Read è automatico.
    4. Premi Generate token e incolla qui il codice generato.

    Il codice viene inviato solo all’API di GitHub e rimane nella memoria di questa scheda. Non viene salvato nel sito o nel browser: chiudendo o ricaricando la pagina dovrai reinserirlo. Non incollarlo in chat. Non è la chiave EODHD.
